# Drill Notes

This rehearsal exercised a personal GitHub upkeep runbook end-to-end in a disposable sandbox: it recorded the current starred-repository list as a CI-tooling shortlist, stood up a fresh repository with an Actions workflow whose single job sleeps for about 30 minutes on pushes to the default branch and manual dispatch, started a run of that workflow and cancelled it while it was still running, split a "hung CI handling" issue into two sub-issues before detaching one of them to confirm the parent's sub-issue list updates as expected, and finally opened a pull request from a drill-notes branch adding this file so the whole sequence — workflow setup, hung-run cancellation, issue decomposition, and pull-request review — could be verified against a real GitHub account before being trusted on production projects.
